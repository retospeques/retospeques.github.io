Así es cada reto

Siempre el mismo ritmo, para que sepan qué viene y se animen a participar.

  1. Mira¡Mira! Una manzana…

    Cada dibujo aparece justo cuando se nombra.

  2. Escucha¿Cuántas hay?

    Una pregunta sencilla, con voz cercana.

  3. PiensaPiensa…

    Una pausa para que encuentre la respuesta.

  4. Responde¡Tres manzanas!

    La solución llega después de pensar.

  5. Celebra¡Lo has hecho genial!

    Cada acierto termina con una fiesta.
